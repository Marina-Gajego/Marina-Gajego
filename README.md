## 💙 Sobre mim

- 🧪 Engenheira de Qualidade de Software apaixonada por automação de testes
- 🎭 Testes **E2E** com Playwright + TypeScript e testes de **API** com Java, REST Assured e Cucumber
- 🤖 Explorando **IA no dia a dia de QA**: agentes (Claude Code, Copilot, Gemini), Playwright MCP e workflows BMad
- 🔁 Testes integrados a **CI/CD**, validação em banco e contratos com JSON Schema
- 📍 Ribeirão Preto, São Paulo, Brasil
- 🦖 Fun fact: sou apaixonada por dinossauros
